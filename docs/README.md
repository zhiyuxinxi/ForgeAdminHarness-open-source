## 按角色阅读

**业务、产品和测试人员**：上手指南 → 第一次只读对话 → 按需选一张工作卡 → 按约定结果验收。

**技术评估者**：项目首页 → 功能说明与 AI 能力总览 → 架构 → 公开版本与安装限制。先确认适配成本，再投入环境建设。

**部署维护者**：上手指南 → 安全边界 → 运维与故障排查。当前公开版是源码快照，脚本顺序说明不等于全新环境安装已验收。

## 文档边界

顶层文档面向此公开仓库。`ai-delivery-playbook/` 是工作卡与说明，其中 `_meta/` 和标注日期的模型样本保留历史背景，不能作为当前运行状态或兼容性承诺。运行用 Skills、提示词、配置和测试应按各自版本一起维护。

维护仓库持续演进，公开快照按阶段整理同步。请以本仓库代码和[公开版本说明](release-status.md)为准；内部新增能力或修复在公开同步前不视为本版本已包含。

目录分层和阅读顺序见[A0项目入口](00-a0/00-read-first.md)，当前公开快照见[A1当前版本](10-a1/00-current.md)。
