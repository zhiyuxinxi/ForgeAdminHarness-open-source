# 阶段合同与一致性门禁

## 开工前合同

进入编码前，至少确认以下合同：

| 合同 | 必须包含 |
|---|---|
| 业务合同 | 术语、规则、状态、异常、权限、验收标准 |
| 数据合同 | 对象、字段语义、必填、唯一、关联、审计、迁移 |
| 页面合同 | 页面目的、字段、动作、状态、权限、空/错/加载体验 |
| 接口合同 | 路径、方法、输入、输出、错误、权限、幂等、分页 |
| 流程合同 | 状态、事件、参与者、条件、退回/撤回/终止、审计 |

## 一致性检查

编码前后都要核对：

- PRD 的每个字段和状态是否能映射到页面、接口和数据；
- 前端字典值是否与后端校验和数据库存储一致；
- 前端隐藏按钮后，后端是否仍独立鉴权；
- 删除、导出、批量操作是否遵守数据范围；
- 流程状态是否存在后端绕过或无法到达的路径；
- 时间、金额、编码、空值和枚举是否有统一格式；
- 迁移是否兼容已有数据，是否有回退或前向修复方案。

若合同冲突，先输出“冲突项—影响层—建议归一结果—责任人”，不得让前后端各自猜测。
