# 配置、日志、缓存与监控任务单

模板编号：`FA-OPS-03`  
平台依赖：系统配置、操作/登录日志、在线用户、受管缓存策略、服务监控  
证据：Forge Admin v1.1.2 固定源码（S1）

## 人与 AI 的分工

业务人员只说明哪些值需要运营调整、哪些动作必须追责、哪些业务异常需要告警。AI 自行读取配置、日志、缓存和监控实现，提出生效/失效与观测方案；技术/安全/运维复核。产品不选择缓存 key、TTL 或日志切面。

## 可直接复制给 AI

```text
请审查 {{功能}} 需要的动态配置、审计日志、缓存和监控。先读取 Forge Admin 当前系统配置、OperationLog、缓存策略和监控实现；不要为方便而降低安全边界。

可配置项：{{名称、默认、变更频率}}
需要审计的动作：{{列表}}
拟缓存数据：{{内容、租户、更新频率}}
关键指标与告警：{{成功率、延迟、积压等}}

输出：
1. 哪些是启动配置、动态业务配置或 Secret；Secret 不进入普通配置表；
2. 配置类型/范围/默认/校验/变更权限/生效方式/回滚；
3. OperationLog 的动作、对象 ID、结果和脱敏字段；
4. 缓存 key 的租户/版本维度、TTL、失效和穿透/击穿策略；
5. 清缓存和改策略的权限、影响评估和审计；
6. 指标、日志关联 ID、告警阈值、排障入口和测试。
```

## 停止条件

配置中包含密码、Token、AK/SK，或清缓存会影响全平台且缺少范围/回退时，停止实现并转安全评审。日志不得记录凭据、完整身份证号或不必要的业务正文。
