# 外部 API 与 AI 能力接入任务单

模板编号：`FA-OPS-04`  
平台依赖：external/outbound/API config、AI 供应商/模型/智能体/会话/Skill 相关模块  
证据：Forge Admin v1.1.2 固定源码（S1）

## 人与 AI 的分工

业务人员确认为什么调用、允许发送哪些数据、失败时业务怎样降级、哪些结果必须人工复核。AI 自行读取出站白名单、凭据引用、模型/外部 API 配置和相似调用，设计安全与可靠性；技术/安全人员复核。产品不接触密钥，也不填写 HTTP 客户端或模型路由实现。

## 可直接复制给 AI

```text
请为 {{外部服务或 AI 场景}} 设计受控接入。先读取当前 outbound 白名单、外部系统/API 配置、AI 供应商/模型路由/会话和相似调用；不要把凭据写进代码、模板或日志。

业务目的与允许发送的数据：{{说明}}
目标服务/模型：{{名称}}
调用量、延迟和成本上限：{{业务量级和可接受等待由人说；技术阈值由 AI/技术建议}}
失败或不可用时的业务降级：{{说明}}
是否会执行写操作或产生外部副作用：{{是/否}}

输出：出站目标白名单、认证凭据引用、数据分类与脱敏、请求/响应合同、超时/重试/熔断/限流、幂等、审计、模型路由、提示词/Skill 版本、人工复核、降级、测试和运行指标。

AI 只能在获准范围内建议或执行动作。涉及发版、删除、资金、权限、真实客户数据和外部消息时，保留人工门禁；模型回答不能作为业务事实的唯一来源。
```

## 验收

白名单外目标被拒绝；凭据从受控位置注入且不出现在日志；超时与限流不拖垮主请求；模型输出按结构校验；提示词/Skill 可追踪版本；失败时业务能安全降级或人工接管。
