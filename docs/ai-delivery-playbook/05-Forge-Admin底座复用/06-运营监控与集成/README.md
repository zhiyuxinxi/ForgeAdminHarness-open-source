# 运营、监控与集成

本目录处理“功能上线后还会发生什么”：通知是否可靠、定时任务能否重跑、配置是否安全、日志是否可查、缓存是否可控、外部系统失败如何补偿、AI 调用如何治理。

本目录是 AI/技术专项合同。业务人员只需要说清触发事件、接收人或处理对象、可接受时限、失败影响和人工接管方式；项目模块、配置、代码路径和验证由 AI 自行读取，技术/运维复核。

这些任务单依据 Forge Admin v1.1.2 的 message/job/system/external/AI 等源码模块和技术 Starter 编写，但当前固定提交没有对应的专项官方 Skill。因此 AI 必须读取目标项目相似模块、配置、测试和 migration，不能只凭本模板直接生成。

- [通知消息与公告](01-通知消息与公告任务单.md)：接收人、模板、已读、重试、审计；
- [定时任务与补偿](02-定时任务与补偿任务单.md)：调度、并发、幂等、失败恢复；
- [配置日志缓存监控](03-配置日志缓存监控任务单.md)：运行配置、审计、观测和安全操作；
- [外部 API 与 AI 能力接入](04-外部API与AI能力接入任务单.md)：凭据、白名单、超时、限流、脱敏和降级。

这些平台能力通常跨模块，业务需求必须先完成领域边界；不能把核心业务逻辑藏在定时任务、消息模板或动态配置里。
