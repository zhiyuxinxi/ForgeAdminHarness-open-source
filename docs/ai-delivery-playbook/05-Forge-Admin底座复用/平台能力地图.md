# Forge Admin 平台能力地图

这张地图用于回答“是复用、配置、扩展还是新建”。标为源码验证不代表部署环境自动开放，仍需检查当前项目配置和权限。

业务人员可以只阅读第一列，用自己的话指出需要；AI 负责核对已有底座、选择优先动作并解释为什么。类名和组件名是给 AI/技术人员的证据索引，不是产品填写项。

| 业务需求 | 已有底座 | 优先动作 | 不应做什么 |
|---|---|---|---|
| 用户账号、个人资料、启停、重置密码 | `SysUser`、用户管理接口与页面 | 关联平台用户 ID，复用账号生命周期 | 新建第二套登录用户表 |
| 部门/组织树、负责人、上下级 | `SysOrg`，支持树、懒加载、切换当前组织 | 复用组织 ID 和当前组织上下文 | 用自由文本存部门名 |
| 岗位 | `SysPost`、用户岗位关系 | 把岗位作为任职关系，不冒充角色权限 | 用岗位名称直接鉴权 |
| 角色、菜单、按钮、API 资源 | `SysRole`、`SysResource`、角色资源关系 | 按页面/按钮/API 建立可审计资源 | 只在前端隐藏按钮 |
| 多租户 | `TenantEntity`、租户上下文与隔离 | 业务表继承租户基类并测试跨租户拒绝 | 手工信任前端 tenantId |
| 数据范围 | datascope Starter、角色/模块数据范围 | 选择全部、本人、本组织、本组织及下级、自定义、租户全部 | 只在 Service 拼一个临时 org 条件 |
| 状态、类型、有限选项 | 字典类型/数据、`DictSelect/DictTag` | 使用稳定字典码、迁移初始化、后端校验 | 前端硬编码中文数组 |
| 行政区划 | `SysRegion`、`RegionTreeSelect` | 存稳定区域编码，显示时解析名称 | 保存完整地址文本替代区划码 |
| 附件和受权图片 | 文件元数据/存储配置、`AuthImage` | 存文件 ID，通过授权 URL 显示 | 把宿主机绝对路径或永久 URL 入业务表 |
| Excel 导入导出 | Excel Starter、动态导入导出配置 | 配置列、字典映射、错误行和权限 | Controller 手写一套不受控 Excel 工具 |
| 普通 CRUD 页面 | `AiCrudPage` + 官方 CRUD Skill | 选择单表/主子表/左树右表黄金路径 | 自造重复 CRUD 壳和 PUT/DELETE 合同 |
| 审批流程 | Flowable 插件 + 官方流程 Skill | 选择低代码或代码优先模式 | 用 status 字段和几个按钮冒充流程引擎 |
| 通知公告/消息 | message 插件、通知与阅读记录 | 明确接收人、模板、重试和审计后复用 | 在事务里直接发外部消息且无补偿 |
| 定时任务 | job 插件、任务配置与日志 | 设计幂等、并发、补偿、告警 | 用 Controller 临时触发代替任务治理 |
| 操作/登录日志、在线用户、监控、缓存 | system 插件相关模块 | 复用观测与审计能力 | 为通过测试关闭日志或审计 |
| AI 供应商、模型、智能体、会话、Skill | AI 插件 | 配置受控供应商、模型路由和提示词 | 把密钥写进模板或仓库 |
| 低代码应用/对象/页面/发布 | 应用中心与对象/页面设计源码模块 | 先做“低代码或代码开发选择” | 未核对运行时边界就承诺零代码交付 |
| AI 数据大屏 | report 服务与设计器 | 单独设计数据源、权限、发布和嵌入 | 让前端大屏直连内部数据库 |

## 选择规则

- **直接复用**：底座语义与业务语义一致，例如用户、组织、字典、文件；
- **配置扩展**：能力已有，但需新增资源、字典、Excel 配置、流程定义；
- **业务扩展**：底座提供框架，业务仍需表、接口和页面，例如交付项目台账；
- **新建能力**：当前版本无对应语义，且经过源码/Skill/相似模块检查后才能新建。

业务人员只需说明“我要谁在什么范围内完成什么动作，结果如何验收”；AI 必须把这个业务描述映射到上表，并报告复用点与新增点。
