# Excel 导入导出任务单

模板编号：`FA-COMMON-03`  
平台依赖：Excel Starter、`sys_excel_export_config`、`sys_excel_column_config`、动态导入导出引擎  
Skill 依赖：`forge-codegen-crud`  
证据：固定源码、官方 Skill、交付台账 POC 实际导出冒烟（S1/S2/S3）

## 人与 AI 的分工

业务人员提供 Excel 样例，确认每列含义、导入是新增还是更新、错误时整批还是部分接受，以及谁能导出哪些数据。AI 自行读取统一 Excel 引擎、配置、DTO/VO、权限和相似实现；技术/测试复核批量、事务和真实 xlsx。产品不填写 Bean、查询方法或配置表字段。

## 可直接复制给 AI

```text
请为 {{业务对象}} 接入 Forge Admin 统一 Excel 导入/导出能力。完整读取官方 CRUD Skill 的 SQL seeds/验证清单，并检查当前版本 Excel 配置实体、相似 Controller 与运行引擎。

导入目的：{{新增/更新/混合}}
导出范围：{{当前筛选/勾选/全部允许数据}}
字段清单：{{可直接提供样例 Excel；AI 先提取列草案}}
字典/日期/金额/用户/组织字段：{{映射规则}}
最大行数、异步要求：{{业务量级由人说明；技术阈值由 AI/技术建议}}
权限与数据范围：{{说明}}

输出并在获准时实现：
1. 唯一配置键、配置类型、数据源 Bean、查询方法和是否分页；
2. 列配置、导入/导出开关、字典与日期格式、示例值；
3. 模板下载、导入、导出接口与独立权限码；
4. 每行字段校验、业务唯一性、行号错误、批次内重复和部分失败策略；
5. 导出必须沿用当前用户租户/数据范围，防止全库导出；
6. 大文件、超时、重复提交、任务状态、文件清理和审计；
7. 幂等 migration、服务/Mapper 方法和测试；
8. 用真实生成的 xlsx 做冒烟：HTTP 状态、Content-Type、非空文件、代表性单元格和字典文案。

不要另写一套 EasyExcel/POI Controller 绕开平台配置。未确认“更新现有记录”的匹配键和冲突策略时，导入只允许新增草案。
```

## 必验问题

- 模板列、DTO/VO 字段和配置字段是否同名；
- 导入字典显示文案能否稳定转换为编码；
- 日期、金额和长 ID 是否被 Excel 自动改写；
- 错误行是否能定位且不会悄悄落一半数据；
- 导出查询不分页，但必须有行数上限、权限和数据范围；
- 接口返回 200 不代表文件可用，必须实际解析一次 xlsx。

## 停止条件

需要覆盖更新主数据、一次导入会触发流程/资金/外部消息，或数据量可能影响线上服务时，必须先评审事务边界、异步方案和回退策略。
