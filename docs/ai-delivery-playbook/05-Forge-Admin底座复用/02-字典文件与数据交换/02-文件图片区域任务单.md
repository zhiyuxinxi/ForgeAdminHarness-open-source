# 文件、图片与区域任务单

模板编号：`FA-COMMON-02`  
平台依赖：文件 Starter、文件元数据/存储配置、`AuthImage`、`RegionTreeSelect`  
证据：Forge Admin v1.1.2 固定源码（S1）

## 何时使用

业务涉及合同、附件、头像、现场照片、证明材料或行政区划时使用。普通长文本和结构化明细不应伪装成附件。

## 人与 AI 的分工

业务人员确认文件用途、谁能查看、数量/大小预期、保留期限和区域精度。AI 自行读取文件 API、`AuthImage`、`RegionTreeSelect` 与存储配置，设计授权和数据引用；安全/技术人员复核扫描、越权和清理。产品不填写文件表、URL 或宿主机路径。

## 可直接复制给 AI

```text
请为 {{业务功能}} 设计并接入 Forge Admin 文件/图片/区域能力。先读取当前文件 API、AuthImage、RegionTreeSelect、相似业务模块和存储配置，不要自建永久公开下载 URL。

文件类型与用途：{{合同/照片/附件等}}
单个/多个、数量和大小限制：{{规则}}
允许格式与安全要求：{{规则}}
谁可上传、预览、下载、替换、删除：{{角色与数据范围}}
区域精度：{{省/市/区县/乡镇/未知}}

输出：
1. 业务表保存 file_id、附件关系表或 region_code 的建议；
2. 上传、绑定、替换、删除与业务事务的一致性策略；
3. 文件内容类型、扩展名、大小、恶意文件和重复上传校验；
4. 授权预览/下载链路，图片使用 AuthImage 的方式；
5. 临时文件、孤儿文件、业务记录删除后的保留/清理策略；
6. RegionTreeSelect 回显与后端区域编码存在性校验；
7. 越权 fileId、过期 URL、跨租户文件、失败重试和历史附件测试。

不得把宿主机绝对路径、对象存储密钥、永久签名 URL 或文件二进制直接写入普通业务字段。
```

## 人工验收

用无权限用户直接访问已知 fileId，必须被拒绝；业务记录删除后按保留规则处理文件；图片预览失败有明确占位和错误；区域编码与显示名称一致。

## 停止条件

文件保留期限、敏感级别、病毒扫描或跨租户共享规则未确认时，只做设计，不批量迁移历史附件。
