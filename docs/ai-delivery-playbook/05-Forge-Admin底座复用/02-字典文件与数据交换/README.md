# 字典、文件与数据交换

这些能力看似“辅助功能”，但最容易造成前后端不一致、越权下载和批量脏数据。本目录坚持三个原则：

- 字典编码是稳定合同，显示文案可演进；
- 业务表保存文件 ID/区域编码，不保存宿主机路径或临时授权 URL；
- 导入导出是独立高风险能力，必须有权限、行级校验、错误报告和审计。

使用顺序：有限选项先走 [字典与联动字典](01-字典与联动字典任务单.md)；附件/图片/区域走 [文件图片区域](02-文件图片区域任务单.md)；批量交换走 [Excel 导入导出](03-Excel导入导出任务单.md)。

若字段本身拥有大量属性、独立权限、生命周期或频繁增删，应建业务表，不应为了省事塞进字典。
