# 字典与联动字典任务单

模板编号：`FA-COMMON-01`  
平台依赖：`SysDictType`、`SysDictData`、`DictSelect`、`DictTag`  
证据：Forge Admin v1.1.2 固定源码与 CRUD Skill（S1/S2）

## 人与 AI 的分工

业务人员提供选项的中文含义、可否停用、父子关系和历史影响。AI 自行查找已有字典及列表、详情、导入导出等使用位置，设计稳定编码和 migration；技术人员复核后端校验。产品不需要先命名 `dict_type` 或填写数据库配置。

## 可直接复制给 AI

```text
请把 {{字段/选项组}} 接入 Forge Admin 数据字典。先检查已有字典、相似页面、SysDictType/SysDictData 和 DictSelect/DictTag；不要在前端硬编码选项。

字段业务含义：{{说明}}
候选值：{{只写业务文案也可以；稳定编码由 AI 建议}}
是否可停用/排序/设默认：{{规则}}
是否存在父子或级联联动：{{例如省→市、类型→子类型}}
是否参与流程条件、统计、导入导出：{{说明}}

输出并在获准时实现：
1. 判断使用字典还是业务表，并说明边界；
2. dict_type、字典项 value/label/sort/status/default 和联动字段；
3. tenant_id=1 的幂等 migration，禁止删除仍被历史记录引用的项；
4. 数据库存编码、后端合法性校验、VO 返回和前端 DictSelect/DictTag 显示；
5. Excel 导入时文案转编码、导出时编码转文案；
6. 未知值、停用值、改名、排序变化和历史显示策略；
7. 正常、非法值、停用值、联动不匹配和缓存刷新测试；
8. 列表、详情、打印和 Excel 往返中不得暴露原始 code；保留未知值显式兜底，但不得静默映射为另一个合法值。

编码不可因中文文案修改而变化。流程分支依赖的值必须经过业务负责人确认，普通管理员不得随意新增流程关键值。
```

## 联动字典注意点

当前 `DictSelect` 支持与 `linkedDictType/linkedDictValue` 等联动信息配合。AI 必须基于目标版本源码确认实际属性和数据形状，不能只写一个前端 watch。服务端仍需验证子项确实属于所选父项。

## 验收与停止条件

验收至少覆盖页面选择、编辑完整回显、列表标签、详情、打印、接口非法编码、Excel label→value→label 往返和停用后的历史记录。迁移必须向前增加或显式升级字典配置，不修改历史 Flyway，也不能用 `INSERT ... NOT EXISTS` 静默保留不兼容旧配置。若候选值会改变审批、计费或法定统计含义，先确认版本演进方案再写迁移。
