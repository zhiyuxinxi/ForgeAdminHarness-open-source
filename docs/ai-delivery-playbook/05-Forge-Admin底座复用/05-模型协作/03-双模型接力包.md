# 双模型接力包

模板编号：`MODEL-HANDOFF-01`  
目标：让下一个模型只读必要事实和文件，避免复制整个聊天记录

> AI/技术执行合同：正常情况下使用者只需说“为当前任务生成接力包”。下面 8 部分由上游 AI 从当前工作区、会话和证据中自动填写，用户只补它看不到的外部决定。

## 接力包正文模板

```text
# AI 实施接力包

## 1. 当前目标
{{一句话目标}}

## 2. 唯一工作位置
- 仓库/工作区：{{AI 自动确认}}
- 分支/提交：{{AI 自动确认}}
- 工作区状态：{{AI 自动确认，未知改动注明归属风险}}

## 3. 已确认业务合同
- 对象与字段：{{摘要/路径}}
- 角色与权限：{{摘要/路径}}
- 字典/流程/Excel：{{摘要/路径}}
- 验收标准：{{路径}}

## 4. 已加载平台依据
- AGENTS.md：{{路径}}
- 官方 Skill 与引用：{{列表}}
- 相似模块/迁移：{{列表}}

## 5. 上游模型实际完成
- 新增/修改文件：{{逐项}}
- 关键决定：{{逐项}}
- 已运行验证：{{命令、结果}}
- 未运行验证：{{逐项}}

## 6. 已知风险与待审项
{{唯一键、租户、权限、接口、字典、流程、迁移等}}

## 7. 下游模型本轮任务
{{审核/实现/测试/发布的明确范围}}

## 8. 禁止事项与停止条件
{{不碰生产、不跨项目、不输出密钥、合同冲突先停等}}
```

## 压缩规则

- 用文件路径代替粘贴完整文件；
- 只保留已确认结论和仍影响后续的未知项；
- 不复制模型的长推理、重复命令和已经推翻的方案；
- 命令保留“用途 + 结果 + 日志路径”，不粘贴无关下载日志；
- 对每个“完成”写清证据，对每个“未做”写清原因。

接力包应该足够让下一模型先审查现状，但不能替代它读取当前文件和官方 Skill。
