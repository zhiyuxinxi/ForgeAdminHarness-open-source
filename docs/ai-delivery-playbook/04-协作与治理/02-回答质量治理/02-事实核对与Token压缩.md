# 事实核对与 Token 压缩

这是 AI/实施人员的维护动作。普通使用者只需说明下一轮目标；当前材料、权威来源、重复内容和失效结论由 AI 从会话与项目中整理，不能要求用户重新回忆整段历史。

## 可直接复制给 AI

```text
请把当前材料压缩成下一轮任务需要的最小可靠上下文，并先核对事实冲突。

下一轮唯一目标：{{目标}}
必须保留的权威来源：{{知道就写；AI 还应根据项目规则识别}}
当前材料：{{默认使用当前会话与已读项目文件；外部材料再补}}
字数上限：{{例如 1200 字}}

处理步骤：
1. 找出重复、失效、互相冲突和无来源陈述；
2. 按权威来源优先级选择当前事实，冲突未决则保留双方；
3. 删除不影响下一轮决定的过程、长日志和被否决方案；
4. 用“目标/事实/决定/假设/未决/证据/下一步/停止条件”输出；
5. 文件内容只引用路径与关键段落，不复制全文；
6. 列出被删除信息的类别，确保可追溯但不再注入上下文。

不要为了满足字数上限删除权限、数据、迁移、发布或安全边界。
```

## 人工验收

压缩后的每条事实都能找到来源；旧结论不会因出现次数多而覆盖新权威；下一轮 AI 不需要重新阅读整段历史也能安全继续。

## 停止条件

权威来源互相冲突且会改变执行结果时，不做单一摘要，输出冲突包等待负责人决定。
