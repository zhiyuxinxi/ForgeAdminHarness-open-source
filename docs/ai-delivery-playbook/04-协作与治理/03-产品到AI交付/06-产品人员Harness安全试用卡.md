# 产品人员 Harness 安全试用卡

- 模板编号：`DIALOG-PRODUCT-01`
- 使用者：产品经理、业务负责人、产品 UAT 人员
- 当前状态：可用试点；不能证明非技术人员可以无人值守交付

Policy marker: `PRODUCT_HARNESS_TRIAL_CARD_V1`.

## 你负责的只有三件事

1. 说明谁遇到什么业务问题，希望最后看到什么；
2. 确认业务规则、范围、页面表现和不能接受的结果；
3. 用真实角色操作页面，记录入口、步骤、期望、实际和截图。

你不负责选择类、表、API、加密、Flyway、Maven、pnpm、Docker、SQL、服务重启或部署方式。AI 应自行读取项目并提出技术方案；研发/实施复核技术，Runner 执行发布门禁。

## 不会填时，直接这样开始

### 可直接复制给 AI：产品友好模式

```text
我是本任务的产品/业务人员。请进入产品友好模式，先建立任务草案，不要立即发布。

我想做或修复：{{用自己的话说；只写一句也可以}}
使用者和场景：{{知道就写，不知道可空}}
我希望看到：{{可观察结果}}
参考截图/附件/页面：{{有就提供}}
本次不做：{{知道就写，不知道可空}}

请先加载 forge-task-contract，并自行读取当前项目、工作区、Git 状态、相关代码和现有规范。
从项目能查到的内容由你代填并注明来源，不要让我猜技术字段。
业务问题最多问 3 个，并给推荐；技术决定按项目规范提出方案并标记技术复核人。
第一轮只输出：任务草案、允许动作、会产生的写入、产品验收方法、技术验证方法和停止条件。
```

## AI 给出陌生技术选择题时

产品人员不需要在 RSA、接口风格、数据库模型、组件、构建或部署选项中猜。直接回复：

### 可直接复制给 AI：改成决定卡

```text
这个问题包含我不负责的技术选择。请改成决定卡：
1. 用业务语言说明发生了什么和对功能的影响；
2. 给出推荐方案、理由、风险和是否可回退；
3. 只保留确实需要我确认的业务决定；
4. 技术细节放到后置证据区，并交给技术负责人复核；
5. 如果是平台能力异常，停止当前动作并生成升级卡。
```

## 提交截图或 UI 参考时，你怎样说

你只描述看得见的结果：

- 从哪个菜单/页面进入，做了什么；
- 参考图与当前页面分别是什么；
- 主要在哪种宽度或设备使用；
- 哪些差异最影响使用；
- 正常、空数据、加载、失败、提交中分别应怎样；
- 弹窗内容是否要滚动，底部按钮是否固定；
- 哪些地方允许与参考图不同。

AI 应把这些信息转换成 UI 合同，自己查现有组件和相似页面，并在真实部署页面验证宽屏和窄屏。产品人员不写 CSS，也不负责判断“代码已经改了为什么服务器没变化”。

## AI 说完成后，你怎样验收

产品 UAT 只判断业务是否可用：

1. 用目标角色从真实入口进入；
2. 走一遍最常用的成功路径；
3. 走一遍最重要的失败或无权限路径；
4. 检查文案、字段含义、状态、弹窗、空数据和错误提示；
5. 结果只写 `通过 / 失败 / 未执行 / 证据不足 / 不适用`。

代码、数据库、事务、权限负例、构建、镜像和发布由 AI、研发、测试和 Runner 提供独立证据。产品说“页面可用”不能替代技术门禁，技术测试通过也不能替代产品 UAT。

## 正在执行时又想到别的事

- 同一目标的补充：消息开头写“补充当前任务”；
- 纠正当前事实或验收：写“修正当前任务”，要求 AI 先说明影响；
- 新功能或新交付物：新开会话；
- 必须换掉当前任务：写“停止并替换当前任务”，先让 AI 报告已有写入、运行中动作和恢复点。

当前 Harness 客户端还没有强制的“补充/排队/新任务”输入模式，所以这仍是协作规则，不应宣称产品能力已经自动防冲突。

## 看到这些信号，立即停止并转技术人员

- AI 无法确认当前项目、分支、提交或 Runner 契约；
- AI 要求你运行 Maven、pnpm、Docker、SQL、服务重启或重新部署环境；
- AI 准备安装/创建 MySQL、Redis、数据库、账号或授权；
- 工作区有归属不明的改动，或可能影响他人会话；
- 多次修改后服务器页面仍无变化，却没有“提交 → 构建 → 镜像 → 发布 → 浏览器”的证据链；
- 测试、迁移、权限、发布或回退证据缺失，却声称已经完成；
- 新消息改变了运行中任务的目标或权限。

停止后只保存项目/任务、时间、页面入口、操作步骤、截图、会话引用和可见错误。不要复制口令、API Key、完整客户数据或长日志。

## 这张卡解决不了什么

它只能降低沟通和授权误解，不能替代个人身份、任务认领、分支隔离、会话队列、视觉自动回归、证据面板和机器发布门禁。出现这些问题，应进入 Harness/平台产品改进，不继续要求普通使用者背更多提示词。
