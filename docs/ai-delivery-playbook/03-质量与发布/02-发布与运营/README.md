# 发布与运营

本目录用于把已验收版本安全地送入目标环境，并在上线后观察真实状态。业务人员可以发起、确认业务窗口和验收结果，但发布执行仍受项目权限、安全规则和运行手册约束。

## 使用选择

- 任何项目准备发版：先用 [发布准入评审](01-发布准入评审.md)；
- 当前 Forge/Harness 项目由 AI 执行发布：用 [Forge Harness 受控发布任务单](02-Forge-Harness受控发布任务单.md)；
- 上线后观察、决定继续或回退：用 [上线观察与回退判断](03-上线观察与回退判断.md)。

“生成发布计划”是低风险文档任务；“执行发布”是高影响操作，必须明确目标项目、环境、版本、窗口和授权，二者不能混用。
