# 回答验收与纠偏

适用于 AI 回答过于专业、冗长、混乱，或看似完整却无法用于评审和执行的情况。

普通使用者不需要先诊断技术根因。最少只需指出“我真正想拿到什么”和“哪一部分看不懂/与实际不符”；AI 应自行对照当前任务和上一版回答找偏差。

## 五分钟验收

按以下顺序判断，不先争论措辞：

1. **答没答目标**：是否给出了要求的交付物；
2. **事实是否可靠**：是否标明来源，有无把假设写成事实；
3. **结构是否可执行**：是否有责任人、输入、输出、边界和验收；
4. **上下游是否一致**：术语、状态、字段和权限是否互相冲突；
5. **是否越权**：是否擅自进入编码、数据变更或发布。

## 可复制纠偏指令

```text
你的上一版回答暂不通过验收。不要增加新方案，也不要重复完整背景。

本轮真正目标：{{我要做出的决定或交付物}}
发现的问题（不知道怎样分类时直接写“看不懂/与实际不符”）：
- {{例如：事实和推测混在一起}}
- {{例如：没有异常/权限边界}}
- {{例如：内容很多但没有可验收输出}}

请基于上一版内容重构：
1. 先用不超过 5 行给结论；
2. 分为“已确认事实 / 假设 / 建议 / 待决定 / 证据缺口”；
3. 删除不影响本轮决定的背景、套话和重复内容；
4. 按 {{目标格式}} 输出可直接评审的结果；
5. 如果关键事实不足，只问最多 3 个会改变决定的问题；
6. 不执行下一阶段，不声称未验证事项已完成。
```

## 何时应新开会话

连续两次纠偏仍混乱、当前目标已经变化、旧上下文包含冲突结论，或工具输出挤占大量上下文时，应生成交接包后新开会话，而不是继续叠加提示词。
