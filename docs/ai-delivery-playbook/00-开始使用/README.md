# 开始使用

本目录只解决一个问题：普通使用者怎样在不知道技术细节时安全地开始、验收和续接 AI 工作。

## 最短路径

1. [三分钟快速开始](01-三分钟快速开始.md)：用自然语言开始，不先填技术表；
2. [最少上下文与 AI 代填规则](02-最少上下文包.md)：明确哪些由人提供、哪些由 AI 自己查；
3. [回答验收与纠偏](03-回答验收与纠偏.md)：AI 说得复杂、跑偏或越权时纠正；
4. [会话续接与 Token 控制](04-会话续接与Token控制.md)：任务较长或换人时保留当前真相；
5. [上传完整原型文件夹并让 AI 复刻](05-上传原型文件夹并让AI复刻.md)：通过 WebClient/SFTP 保留 Axure 或前端项目层级并建立 AI 阅读索引。

## 普通使用者只记住四条

- 可以只说一句真实问题，不知道的不要猜；
- AI 应先读取项目并代填草案，只把业务决定交给你；
- 每轮只做一个可验收结果，新任务另开会话；
- 没有真实证据的“完成”按未完成处理。

后续任务单中的占位符都遵循这套分工。任何任务单与这里冲突时，以“人说业务、AI 查项目、技术人员复核技术证据”的责任边界为准。
