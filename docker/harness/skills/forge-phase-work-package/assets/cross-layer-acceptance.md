# Cross-layer Acceptance 阶段交互卡

## 本阶段需要的完整交付与验收资料

- 前七阶段全部 artifact/manifest、完整 cumulative patch 和最新受控验证回执。
- 产品/技术人工复核清单、允许的测试角色/租户/数据边界。

## 本阶段关注点（提示由 Controller 自动生成）

只核对这次交付是否真正满足已确认业务用例，不再修改源码。逐条核对需求覆盖、权限一致性、租户/审计/逻辑删除、API/UI、Long ID、测试证据、人工语义复核和 `cannotClaim`，任何缺口原样保留。Controller 自动生成机器提示；同事只需提供或确认真实业务验收结果。

## 阶段输出与停止条件

- 上游摘要、累计 patch、机器回执和人工结论必须指向同一 candidate。
- 面向同事先说明哪些业务流程已有证据支持、哪些具体步骤仍不能确认，以及实际下一步。只展示与本次结论有关的未完成项，不机械罗列所有治理边界；唯一机器 artifact、证据等级和完整 payload 仍须保留在技术区。
- 静态 PASS 不能替代编译、迁移、浏览器、权限负例、发布或长期健康证据。
- 任一 P0/P1、未决业务决定、失败或必需验证未执行，整体不得标记完成。
