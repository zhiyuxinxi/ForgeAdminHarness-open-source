# pm-skills 方法适配来源

来源：[phuryn/pm-skills](https://github.com/phuryn/pm-skills/tree/c68487d721e419ec87af1ae6412a842978eab785)，固定提交 `c68487d721e419ec87af1ae6412a842978eab785`；2026-10-14读取。这里只适配需求相关方法，不安装上游插件、不执行其脚本、不要求在线访问。

| 上游文件 | 本项目采用的部分 | 主动舍弃的部分 |
| --- | --- | --- |
| `pm-product-discovery/skills/interview-script/SKILL.md` | 围绕真实经历和当前做法提问 | 固定访谈时长、付费意愿问题、每次完整访谈 |
| `pm-product-discovery/skills/summarize-interview/SKILL.md` | 从材料提取现状、问题、期望和未决项 | 无关参与者信息、另建汇总文件、无依据的行动人和日期 |
| `pm-execution/skills/create-prd/SKILL.md` | 简洁目标、范围、非目标及显式假设 | 固定八章节/字数、每次市场细分、缺指标就不输出、另建PRD文件 |
| `pm-execution/skills/wwas/SKILL.md` | 为什么做、做什么、如何验收 | 任意顺序交付的假设、固定Sprint大小 |
| `pm-execution/skills/test-scenarios/SKILL.md` | 角色、前置条件、动作和可观察结果 | 示例指标及无关全面测试 |
| `pm-product-discovery/skills/identify-assumptions-existing/SKILL.md` | 识别能改变方案的假设及最小核实方法 | 固定多角色分析、全风险分类、自动实验 |
| `pm-product-discovery/skills/analyze-feature-requests/SKILL.md`、`prioritize-features/SKILL.md` | 主题归纳、有依据的影响/投入/风险取舍 | 禁止客户设计方案、固定前三/前五、无数据评分 |
| `pm-market-research/skills/customer-journey-map/SKILL.md` | 必要时梳理角色动作、交接和困难 | 默认获客/购买/留存漏斗、情绪评分和新制图工具 |

市场策略、定价、增长、SQL分析、发布编排等不属于本次需求适配，不导入。已有项目权限、领域合同和交付证据约定继续生效。技能内容是指导，不能单独证明真实交付效果。
